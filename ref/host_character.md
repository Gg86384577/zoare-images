# ZOARÉ 短劇主持人角色設定（參考 host_storyboard_pompompurin.png）

## 主持人（主角）
- 身分：ZOARÉ 的批發商老闆，自己有倉庫、自己出貨；短劇的目的是讓團購主和想開團的人知道「可以跟他拿貨」
- 20 出頭台灣男生，瘦、五官柔和，深棕色微亂瀏海蓋到額頭，棕色眼睛，親切帶點調皮
- 黑色寬鬆連帽衫，胸口小銀色 ZOARÉ 刺繡；沒有眼鏡、帽子、飾品
- 口吻：第一人稱「我」，口語短句，像跟朋友講話；不說「便宜」「促銷」，說「划算」「值得」

## 場景與風格
- 主場景：夜晚的批發倉庫（紙箱、貨架、打包桌、膠帶台、出貨單、工作燈），讓人一看就知道手上真的有貨；日系選物店當副場景
- 夜晚的日系選物店，暖琥珀光，木架虛化背景，小光斑；9:16 直式，眼平視，淺景深
- 風格關鍵字：精品質感・生活化・日系氛圍
- 字幕：白色或金色手寫感字體；價格用紅色大字；日本定價先出、批發價後出

## 短劇原則（2026-10-31 起）
- 以故事性、好看為主，Claude 當編導；「猜價格」只是其中一種形式
- 觀眾是團購主，內容要回答他們的問題：賣給誰、怎麼賣、大小款差在哪、日常怎麼用
- 科普差異化 + 日常使用情境 + 趣味，讓人想一直看下去；每集留下集鉤子
- 價格和購買資訊放片尾卡與貼文，不塞進劇情
- EP1《倉庫裡的面試》：兩隻布丁狗（18.5cm 絨毛 / 11cm 珠鍊吊飾）應徵出門夥伴

## 猜價格版結構（備用形式）（60 秒・20 鏡・每鏡 3 秒）
1. 開場丟問題（猜價格時間）
2. 商品登場
3. 問日本定價，給 A/B/C 三選項
4. 賣關子 → 揭曉日本定價
5. 揭曉 ZOARÉ 批發價（一般會員 / VIP）
6. 商品特寫：造型、材質、多角度、尺寸、情境（房間、辦公桌、居家）
7. 自用送禮都適合
8. 同系列其他角色預告
9. 互動：留言想看哪個角色
10. 購買須知：起批、日本出貨時間（非台灣到貨日）
11. 結尾：一起把可愛帶回家 → logo + 日本代購／正品商品／生活選物 + 「把喜歡的日常帶回來」

## 規則
- 價格只用目錄數字；不寫廠商名、品番、條碼、成本
- 不說台灣現貨；出貨時間一律標「日本預計出貨」
- 商品一律用真實商品照當參考，不讓 AI 自己畫
